# Product Original Image Reference

Use this file to register source product images before generating display images or creative images.

## Storage Convention

- Put original images under: `assets/original-images/`
- Naming suggestion: `<sku>-<angle>-<index>.jpg`

## Reference Template

| SKU | Product Type | Original Image Path | Must Keep Features | Forbidden Changes | Target Scene |
|---|---|---|---|---|---|
| demo-sku-001 | home/general object (figurine set) | assets/original-images/demo-sku-001-front.jpg | facial expression style, paint color blocks, ceramic/resin texture, small figurine proportions | remove key paint motifs, reshape face/body proportions, convert to unrelated toy style | studio white background + home shelf display |

## Prompt Notes

- Keep product structure and key details consistent with original image.
- For apparel: preserve fabric texture and garment fit.
- For objects: preserve dimensions ratio and functional parts.
